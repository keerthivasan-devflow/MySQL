
Great! You're asking about this SQL query:

```sql
SELECT * 
FROM employee 
WHERE (dept_name, salary) IN (
    SELECT dept_name, MAX(salary) 
    FROM employee 
    GROUP BY dept_name
)
```

---

### ✅ **Goal:**

> Select all employees who have the **maximum salary in their respective department**.

This includes handling cases where **multiple employees** share the same max salary in a department.

---

### 🧾 **Sample `employee` Table:**

| emp\_id | name  | dept\_name | salary  |
| ------- | ----- | ---------- | ------- |
| 1       | Alice | HR         | 50,000  |
| 2       | Bob   | HR         | 70,000  |
| 3       | Carol | HR         | 70,000  |
| 4       | David | IT         | 80,000  |
| 5       | Eva   | IT         | 100,000 |
| 6       | Frank | Sales      | 55,000  |
| 7       | Grace | Sales      | 50,000  |

---

### 🔁 **Step-by-Step Execution**

#### 🔹 Step 1: Execute the subquery

```sql
SELECT dept_name, MAX(salary)
FROM employee
GROUP BY dept_name;
```

This gives the max salary **per department**:

| dept\_name | max(salary) |
| ---------- | ----------- |
| HR         | 70,000      |
| IT         | 100,000     |
| Sales      | 55,000      |

---

#### 🔹 Step 2: Outer query compares (dept\_name, salary)

Now the outer query does:

```sql
SELECT *
FROM employee
WHERE (dept_name, salary) IN (
    ('HR', 70000),
    ('IT', 100000),
    ('Sales', 55000)
)
```

So it finds all rows in the `employee` table where **both** the `dept_name` and `salary` match one of those pairs.
