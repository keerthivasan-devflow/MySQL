### 🔍 **Query to Execute:**

```sql
SELECT * 
FROM employee e1 
WHERE salary > (
    SELECT AVG(salary) 
    FROM employee e2 
    WHERE e1.dept_name = e2.dept_name
);
```

### ✅ **Goal:**

> Get all employees whose salary is **greater than the average salary of their own department**.

---

### 🧾 **Sample Data:**

Let’s assume we have the following `employee` table:

| emp\_id | name    | dept\_name | salary  |
| ------- | ------- | ---------- | ------- |
| 1       | Alice   | HR         | 50,000  |
| 2       | Bob     | HR         | 60,000  |
| 3       | Charlie | HR         | 70,000  |
| 4       | David   | IT         | 80,000  |
| 5       | Eva     | IT         | 100,000 |
| 6       | Frank   | Sales      | 55,000  |
| 7       | Grace   | Sales      | 50,000  |

---

### 🔁 **Step-by-Step Execution:**

#### Step 1: Correlated Subquery (for each row in `e1`)

The subquery:

```sql
SELECT AVG(salary) 
FROM employee e2 
WHERE e1.dept_name = e2.dept_name
```

will compute the **average salary of the department** that the current outer employee belongs to.

Let’s go through each employee:

---

#### 🔄 For **Alice (HR, 50,000)**:

* Subquery: `AVG(salary)` where `dept_name = 'HR'`
* HR salaries = \[50,000, 60,000, 70,000] → average = 60,000
* Alice’s salary (50,000) < 60,000 → ❌ Not included

---

#### 🔄 For **Bob (HR, 60,000)**:

* HR average = 60,000
* Bob’s salary = 60,000 → Equal → ❌ Not included

---

#### 🔄 For **Charlie (HR, 70,000)**:

* HR average = 60,000
* Charlie’s salary = 70,000 > 60,000 → ✅ Included

---

#### 🔄 For **David (IT, 80,000)**:

* IT salaries = \[80,000, 100,000] → average = 90,000
* David’s salary = 80,000 < 90,000 → ❌ Not included

---

#### 🔄 For **Eva (IT, 100,000)**:

* IT average = 90,000
* Eva’s salary = 100,000 > 90,000 → ✅ Included

---

#### 🔄 For **Frank (Sales, 55,000)**:

* Sales salaries = \[55,000, 50,000] → average = 52,500
* Frank’s salary = 55,000 > 52,500 → ✅ Included

---

#### 🔄 For **Grace (Sales, 50,000)**:

* Sales average = 52,500
* Grace’s salary = 50,000 < 52,500 → ❌ Not included

---

### ✅ **Final Result Set:**

| emp\_id | name    | dept\_name | salary  |
| ------- | ------- | ---------- | ------- |
| 3       | Charlie | HR         | 70,000  |
| 5       | Eva     | IT         | 100,000 |
